## 04.11.2026 (4) · `feature/stage5-history` · рабочий ПК — признак «не медицинское изделие»

**Обнаружено**: CPV не различает — у всех 283 лотов 21641880 код 33100000, включая бумагу и DVD-R. Словарь
названий тоже нельзя: у 76 оферт по термобумаге есть DM (бумага зарегистрирована), а DVD-R Ivan принял без DM.

**Сделано** (`src/amdm/medical.py`): тип изделия — первое слово названия лота; реестр ищет записи с таким
названием (основа слова — «Cabluri» = «Cablu»; для слов с диакритикой — кусок без неё). Ни одна запись не
начинается с этого слова — не медицинское: verde «регистрация не требуется, проверить ISO/CE». Ноль записей по
запросу с буквами a/i/s/t (в реестре бывают с диакритикой: «Caciuli» против «CĂCIULIȚĂ») — «неясно», galben.
Ответ реестра хранится 30 дней (`amdm_type`).

**Цифры — 21641880**: 21 тип у оферт без DM; не медицинский — DVD-R (лот 234, Ecochimie — verde, как у Ivan);
медицинские — бумага, кабели, гель, индикаторы и др.; неясно — 1. Итог AMDM: verde 351, galben 122, rosu 5, fara DM 1.

**Открыто**: «неясно» и спорные типы — вопросом в окне («медицинское ли это изделие?»), ответ запомнить для типа.

## 04.11.2026 (3) · `feature/stage5-history` · рабочий ПК — поиск в реестре AMDM по коду модели

**Сделано**
- Оферта без номера DM (только CE/ISO): код модели ищется в реестре в колонке «Nr. catalog», затем «Model» —
  как Ivan ищет по названию. Тот же производитель и модель — verde «DM не указан, найден по коду …»; код только у
  другого производителя или ничего — galben «возможно, nu este înregistrat (или изделие не медицинское)».
- Запросы и найденное хранятся в копии реестра неделю: повторная проверка — без сайта, секунды.
- В лог — строка на каждый код («код «F4141» в Nr. catalog → DM000466393 FIAB»), сбой одного кода не обрывает поиск.

**Цифры — 21641880**: 60 кодов у оферт без DM, на сайте ~8 мин; verde 334 → 350. Отказы Ivan «nu este inregistrat»:
лоты 215 и 241 — «по коду не найдено», 2 и 248 — «код только у другого производителя»: все жёлтые с причиной
(раньше — только «проверить, что не медицинское»).

**Обнаружено**: в A22 модель часто записана так, что код не вычленить («ECG 5 Lead», «Indicator strip Steam 134C»)
или с пробелом внутри («0013.F02-UNI S-E-21»); короткие коды (4 знака) находят чужие изделия — решает сверка
