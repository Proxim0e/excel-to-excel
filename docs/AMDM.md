# Проверка регистрации AMDM

Берёт номера DM из строки 4 листов `lot N` твоей книги оценки, находит их в реестре
[registru.dispozitive.amdm.gov.md](https://registru.dispozitive.amdm.gov.md) и сверяет
производителя и модель или каталожный номер со строкой 3. Результат — копия книги
с листом **«Verificare AMDM»**. Исходный файл и твои ячейки не меняются.

## Установка (один раз)

```bash
pip install playwright
playwright install chromium
```

Без playwright всё работает по локальной копии (`--offline`).

## Запуск

```bash
python -m src.amdm check "resources/21641880_CDM27_B.xlsx"            # с поиском на сайте
python -m src.amdm check "resources/21641880_CDM27_B.xlsx" --offline  # только локальная копия
python -m src.amdm import-csv "Downloads/export.csv"                  # CSV с сайта (до 5000 записей)
python -m src.amdm probe                                              # если поиск на сайте не работает
```

## Статусы

| Статус | Значение |
| --- | --- |
| verde | номер найден, производитель и модель/каталог совпали |
| galben | найден, но расходится производитель, модель или приказ/дата; или DM нет, есть только ISO/CE |
| rosu | номер не найден в реестре |
| fara DM | нет ни номера DM, ни сертификатов |
| neverificat | номера нет в локальной копии, сайт не опрашивался |

Найденные записи сохраняются в `resources/amdm_registry.sqlite` и в следующий раз
не запрашиваются. «Не найден» перепроверяется на сайте через 7 дней: реестр пополняется
приказами примерно раз в неделю.

## Ограничения

- Процедура удаления из реестра фактически не работает: «найден» не гарантирует, что
  регистрация действует сейчас.
- Разметка таблицы сайта ещё не сверена вживую. Если `check` пишет, что не нашёл колонку
  или строку фильтров, запусти `probe` и пришли файлы из `resources/amdm_probe/`.
- Книги, из которых удалены картинки (папка `xl/media`), открываются нормально.
