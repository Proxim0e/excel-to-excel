# Mapping Guide (columns_map и target_map)

Зачем: вынести соответствия заголовков и целевых ячеек в конфиг, чтобы не менять код.

- columns_map: список допустимых названий колонок в родительском файле для каждого логического поля (nr_lot, denumire и т.д.).
- target_map: ячейки шаблона, куда пишем данные (например, denumire → B1).

Как добавить новый шаблон:
1) Скопировать resources/sample_model.xlsx как новый файл шаблона.
2) Создать отдельный конфиг (например, configs/template_sample_model.yaml) с нужным target_map.
3) В CLI (когда будет) передавать путь к конфигу нужного шаблона.

Советы:
- Сравнение заголовков делай регистронезависимым.
- Не клади секреты в конфиг.
