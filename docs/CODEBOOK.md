### Правила для системы
- Цена участника ≥ 130% базы (строка 9) — автоматическое отклонение по закону; лот, где так у всех, — не присуждён (красная вкладка).
- Голубая строка 1 без изменений шаблона — «не оценивался»: не отказ и не принятие.
- Текст и цвет строки 1 противоречат друг другу — вопрос человеку.
- **Alternativa (голубой) автоматически** (решение Ivan, 04.11.2026): запрос и Anexa 22 юридически не совпадают —
  нет данных или противоречие (не указана совместимость с аппаратом из запроса, другой размер, другое число,
  противоположный признак). Оцениваются все участники, не только до первого зелёного.
- Зелёный автоматически — только при полной уверенности: документы подтверждают модель и параметры, AMDM в
  порядке, карточка товара подтверждена и модель уже принималась человеком на похожем запросе. Иначе — вопрос
  человеку (жёлтый, пока нет ответа).
- DM аппарата у его запчасти / аксессуара / комплекта **не подходит** (решение Ivan, 02.11.2026): регистрация
  аппарата не покрывает изделие, на само изделие нужен ISO (или его собственный DM). Проверка AMDM: модель
  оферты не найдена в записи реестра, а модель из записи названа в названии лота — жёлтый с пометкой
  «DM аппарата … нужен ISO на изделие».
